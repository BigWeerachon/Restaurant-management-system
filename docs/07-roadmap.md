## V1.1 — ใช้งานจริงในร้าน (สถานะ: เสร็จทุกข้อที่ไม่ต้องใช้บัญชีภายนอก)

| งาน | เหตุผล | ตัวชี้วัด | สถานะ |
|---|---|---|---|
| เชื่อม Web ↔ API ผ่าน `DataSource` adapter (สลับ demo/HTTP ด้วย env) | ใช้ข้อมูลจริงหลายเครื่องพร้อมกัน | ทุก e2e ของ UI ผ่านทั้ง 2 adapter | ✅ browser tests ชุดเดียวกัน 72 (เดโม) / 68 (API) ผ่านใน CI — [ADR-0009](adr/0009-datasource.md) |
| Auth UI (Supabase Auth: เบอร์โทร OTP / อีเมล / LINE Login) | เจ้าของสมัครเองได้ | สมัครถึงบิลแรก ≤ 10 นาที | ◐ สมัคร → สร้างร้าน → เครื่องร้าน/PIN ใช้ได้ (อีเมล+รหัสผ่าน, `AUTH_MODE=local`); ตัวเชื่อม Supabase เขียนและทดสอบกับ GoTrue จำลองแล้ว — **รอ URL/anon key ของโปรเจกต์จริง** (และ LINE Login ถ้าต้องการ) |
| Offline queue (IndexedDB + service worker) | เน็ตร้านหลุดบ่อย | ขายต่อได้ 100% เมื่อออฟไลน์, sync ไม่ซ้ำ | ✅ ส่งออเดอร์/รับเงินออฟไลน์ได้ ส่งซ้ำด้วย Idempotency-Key เดิม; เปิดแอปได้โดยไม่มีเน็ต |
| พิมพ์ใบเสร็จ/ตั๋วครัว (ESC/POS ผ่าน WebUSB/Serial/Bluetooth, ลิ้นชักเงินสด) | อุปกรณ์หน้าร้านจริง | พิมพ์ < 1 วินาที | ◐ ทำแล้วและทดสอบกับเครื่องพิมพ์จำลอง (ข้อความไทยทั้งแบบ CP874 และแบบภาพ); **ยังไม่ได้ลองกับเครื่องพิมพ์ความร้อนจริง** |
| ใบกำกับภาษีอย่างย่อ + ขอใบเต็มรูป (เลขผู้เสียภาษีลูกค้า) | ร้านจด VAT | ออกเอกสารถูกรูปแบบกรมสรรพากร | ✅ เลขใบเสร็จแยกต่อเครื่อง POS, ใบเต็มรูปบิลละหนึ่งใบ ห้ามแก้ พิมพ์ A4 (ให้นักบัญชีตรวจรูปแบบก่อนใช้จริง; ใบลดหนี้ยังไม่ทำ) |
| Billing จริง (บัตร/พร้อมเพย์ รายเดือน-รายปี) + dunning ที่ **ไม่ล็อกการขาย** | รายได้ SaaS | ค้างชำระ → จำกัดการเพิ่มเท่านั้น | ◐ ใบแจ้งหนี้, webhook ที่ลงลายมือชื่อ, ทดลอง → ปกติ → ค้างชำระ → จำกัดการเพิ่ม (ขายต่อได้เสมอ) — **รอบัญชีผู้ให้บริการรับบัตรจริง**; ตอนนี้โอน/พร้อมเพย์ + ทีมงานยืนยัน |
| Observability: OpenTelemetry, error tracking, SLO | ดูแลระบบจริง | p95 API < 200ms, error < 0.1% | ✅ [09](09-observability.md) · [10-slo](10-slo.md) (วัดบนเครื่องเดียว: p95 < 200 ms ที่ ~4 คำขอพร้อมกัน / ~85 ต่อวินาที, ผิดพลาด 0 จาก 1,696 คำขอ; เกินนั้นต้องเพิ่ม instance — ยังไม่ได้ลองหลาย instance) |
| CI: browser tests ทั้งสองโหมด + axe + Lighthouse budget | กันถอยหลัง | รันทุก push | ✅ jobs `check`, `e2e` (เดโม/API), `lighthouse` |

ประวัติขาย 30 วันใน Postgres seed ✅ ([checklist 1.2b](v1.1-checklist.md)): `pnpm db:seed:history` เติม ~7,000 บิล (สองสาขา สี่ช่องทาง) พร้อมกะ/สต็อก/ค่าใช้จ่าย ให้โหมด API มีรายงานเต็มเหมือนเดโม — เขียนเป็นแถวโดยตรง (คำสั่งจริงผูกกับ `now()`), ไม่ปิดยอดรายวัน, เลือกรันเอง (เทสต์เบราว์เซอร์ใน CI ต้องการร้านที่ยังไม่เคยขาย)

## V2 — อัตโนมัติ (3–9 เดือน)

| งาน | รายละเอียด |
|---|---|
| **เชื่อมแพลตฟอร์มเดลิเวอรี** | ออเดอร์ Grab/LINE MAN/ShopeeFood เข้าครัวอัตโนมัติ, sync เมนู/ของหมด, ดึงรายงาน payout มากระทบยอดเอง |
| **Open banking / statement API** | ดึงรายการเดินบัญชีอัตโนมัติ → กระทบยอดไม่ต้องอัปโหลด CSV |
| **e-Tax Invoice & e-Receipt** | ใบรับรองดิจิทัล, ส่งกรมสรรพากร |
| **ครัวกลางเต็มรูป** | วางแผนผลิตจากยอดขายคาดการณ์ของทุกสาขา, ใบเบิก, ต้นทุนโอนภายใน |
| **Actual vs Theoretical รายสัปดาห์** | ต้นทุนตามสูตร vs ต้นทุนจากการนับ → ชี้เมนู/พนักงาน/กะที่ส่วนต่างสูง |
| **แอปเจ้าของร้าน (PWA/มือถือ)** | แจ้งเตือน: ยอดต่ำผิดปกติ, ยกเลิกบิลบ่อย, ราคาวัตถุดิบขึ้น, เงินไม่เข้า |
| **ลูกค้าสมาชิก/สะสมแต้ม, QR สั่งที่โต๊ะ** | เพิ่มยอดต่อบิล, ลดงานพนักงาน |
| **ส่งออกบัญชี** | FlowAccount / PEAK / Express format |

## ปีที่ 2 — ความฉลาด (Intelligence)

| ความสามารถ | ข้อมูลที่ใช้ (มีอยู่แล้วตั้งแต่ V1) |
|---|---|
| **พยากรณ์ยอดขายรายชั่วโมง/เมนู** → แนะนำการเตรียมของและจัดกะ | orders + hours + วันในสัปดาห์ + วันหยุด/อากาศ |
| **แนะนำการสั่งซื้ออัตโนมัติ** ตามพยากรณ์ (ไม่ใช่แค่จุดสั่งซื้อ) | stock ledger + lead time ผู้ขาย |
| **ผู้ช่วยตั้งราคา** — ขึ้นราคาเมนูไหนกระทบยอดน้อยที่สุด | menu engineering + ความยืดหยุ่นราคาจากประวัติ |
| **ตรวจจับความผิดปกติ/ทุจริต** — void/ส่วนลด/คืนเงิน/เงินสดขาดผิดรูปแบบ ต่อพนักงาน | audit log + approvals + cash variance |
| **Benchmark แบบไม่ระบุตัวตน** — ต้นทุนอาหาร/GP/ค่าเช่าเทียบร้านประเภทเดียวกัน | ข้อมูลรวมหลายร้าน (opt-in) |
| **AI Copilot ภาษาไทย** — "เดือนนี้กำไรลดเพราะอะไร" ตอบพร้อมตัวเลขและลิงก์ | read model + domain events |
| **Open API & marketplace** สำหรับพาร์ทเนอร์ | contracts + OpenAPI ที่มีอยู่ |
| **ต่างประเทศ (SEA)** — สกุลเงิน/ภาษี/QR payment ต่อประเทศ | tenant settings + cell deployment |

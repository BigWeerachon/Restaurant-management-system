## V1.1 — ใช้งานจริงในร้าน (0–3 เดือน)

| งาน | เหตุผล | ตัวชี้วัด |
|---|---|---|
| เชื่อม Web ↔ API ผ่าน `DataSource` adapter (สลับ demo/HTTP ด้วย env) | ใช้ข้อมูลจริงหลายเครื่องพร้อมกัน | ทุก e2e ของ UI ผ่านทั้ง 2 adapter |
| Auth UI (Supabase Auth: เบอร์โทร OTP / อีเมล / LINE Login) | เจ้าของสมัครเองได้ | สมัครถึงบิลแรก ≤ 10 นาที |
| Offline queue (IndexedDB + service worker) | เน็ตร้านหลุดบ่อย | ขายต่อได้ 100% เมื่อออฟไลน์, sync ไม่ซ้ำ |
| พิมพ์ใบเสร็จ/ตั๋วครัว (ESC/POS ผ่าน WebUSB/Bluetooth, ลิ้นชักเงินสด) | อุปกรณ์หน้าร้านจริง | พิมพ์ < 1 วินาที |
| ใบกำกับภาษีอย่างย่อ + ขอใบเต็มรูป (เลขผู้เสียภาษีลูกค้า) | ร้านจด VAT | ออกเอกสารถูกรูปแบบกรมสรรพากร |
| Billing จริง (บัตร/พร้อมเพย์ รายเดือน-รายปี) + dunning ที่ **ไม่ล็อกการขาย** | รายได้ SaaS | ค้างชำระ → จำกัดการเพิ่มเท่านั้น |
| Observability: OpenTelemetry, error tracking, SLO | ดูแลระบบจริง | p95 API < 200ms, error < 0.1% |

## V2 — อัตโนมัติ (3–9 เดือน)

| งาน | รายละเอียด |
|---|---|
| **เชื่อมแพลตฟอร์มเดลิเวอรี** | ออเดอร์ Grab/LINE MAN/ShopeeFood เข้าครัวอัตโนมัติ, sync เมนู/ของหมด, ดึงรายงาน payout มากระทบยอดเอง |
| **Open banking / statement API** | ดึงรายการเดินบัญชีอัตโนมัติ → กระทบยอดไม่ต้องอัปโหลด CSV |
| **e-Tax Invoice & e-Receipt** | ใบรับรองดิจิทัล, ส่งกรมสรรพากร |
| **ครัวกลางเต็มรูป** | วางแผนผลิตจากยอดขายคาดการณ์ของทุกสาขา, ใบเบิก, ต้นทุนโอนภายใน |
| **Actual vs Theoretical รายสัปดาห์** | ต้นทุนตามสูตร vs ต้นทุนจากการนับ → ชี้เมนู/พนักงาน/กะที่ส่วนต่างสูง |
| **แอปเจ้าของร้าน (PWA/มือถือ)** | แจ้งเตือน: ยอดต่ำผิดปกติ, ยกเลิกบิลบ่อย, ราคาวัตถุดิบขึ้น, เงินไม่เข้า |
| **ลูกค้าสมาชิก/สะสมแต้ม, QR สั่งที่โต๊ะ** | เพิ่มยอดต่อบิล, ลดงานพนักงาน |
| **ส่งออกบัญชี** | FlowAccount / PEAK / Express format |

## ปีที่ 2 — ความฉลาด (Intelligence)

| ความสามารถ | ข้อมูลที่ใช้ (มีอยู่แล้วตั้งแต่ V1) |
|---|---|
| **พยากรณ์ยอดขายรายชั่วโมง/เมนู** → แนะนำการเตรียมของและจัดกะ | orders + hours + วันในสัปดาห์ + วันหยุด/อากาศ |
| **แนะนำการสั่งซื้ออัตโนมัติ** ตามพยากรณ์ (ไม่ใช่แค่จุดสั่งซื้อ) | stock ledger + lead time ผู้ขาย |
| **ผู้ช่วยตั้งราคา** — ขึ้นราคาเมนูไหนกระทบยอดน้อยที่สุด | menu engineering + ความยืดหยุ่นราคาจากประวัติ |
| **ตรวจจับความผิดปกติ/ทุจริต** — void/ส่วนลด/คืนเงิน/เงินสดขาดผิดรูปแบบ ต่อพนักงาน | audit log + approvals + cash variance |
| **Benchmark แบบไม่ระบุตัวตน** — ต้นทุนอาหาร/GP/ค่าเช่าเทียบร้านประเภทเดียวกัน | ข้อมูลรวมหลายร้าน (opt-in) |
| **AI Copilot ภาษาไทย** — "เดือนนี้กำไรลดเพราะอะไร" ตอบพร้อมตัวเลขและลิงก์ | read model + domain events |
| **Open API & marketplace** สำหรับพาร์ทเนอร์ | contracts + OpenAPI ที่มีอยู่ |
| **ต่างประเทศ (SEA)** — สกุลเงิน/ภาษี/QR payment ต่อประเทศ | tenant settings + cell deployment |

# ADR-0003: เงินเป็นสตางค์ (integer) ในโค้ด และ numeric ในฐานข้อมูล

- สถานะ: ยอมรับ · วันที่: 2026-09-27

## การตัดสินใจ
- TypeScript: `Satang` = จำนวนเต็ม, ปัดด้วย `divRound` (หารจำนวนเต็มแบบปัดครึ่งออกจากศูนย์ — ตรงกับ `round()` ของ Postgres numeric), แบ่งเงินด้วย `allocate` (ไม่มีสตางค์หาย)
- Postgres: `numeric(14,2)` เงิน, `numeric(14,4)` ปริมาณ/ต้นทุนต่อหน่วย
- API รับ/ส่งเงินเป็นสตริงทศนิยม ไม่ใช่ float
- VAT แยกจากราคารวมด้วยสูตรเดียวกันทั้ง SQL และ `pricing.ts` (145.00 → VAT 9.49)

## ผลที่ตามมา
- ✅ ยอดบนจอ POS ตรงกับเซิร์ฟเวอร์ทุกสตางค์ (parity test)
- ⚠️ UI ต้องแปลงหน่วยก่อนแสดง (`formatBaht`)

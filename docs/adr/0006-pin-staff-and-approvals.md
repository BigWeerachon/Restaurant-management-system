# ADR-0006: พนักงานใช้ PIN + อนุมัติด้วย PIN ครั้งเดียว

- สถานะ: ยอมรับ · วันที่: 2026-09-27

## การตัดสินใจ
- membership ไม่ต้องมี user (อีเมล) — พนักงานพาร์ทไทม์ใช้ PIN 4–6 หลักบนเครื่องร้าน (bcrypt, unique ต่อร้าน, rate limit)
- token พนักงานอายุสั้น มี claim `mid`
- การกระทำเสี่ยงสร้าง approval ที่ใช้ได้ **ครั้งเดียวภายใน 5 นาที** ผูกกับ permission และผู้อนุมัติ
- ต้องมีเจ้าของร้านที่ active อย่างน้อย 1 คนเสมอ (trigger)

## ผลที่ตามมา
- ✅ สลับคนบนเครื่องเดียวได้ในไม่กี่วินาที และตรวจย้อนหลังได้ว่าใครอนุมัติอะไร
- ⚠️ PIN คาดเดาง่ายกว่ารหัสผ่าน → ใช้เฉพาะบนอุปกรณ์ที่ลงทะเบียน (devices) + rate limit

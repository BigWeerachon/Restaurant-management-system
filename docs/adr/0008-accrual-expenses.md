# ADR-0008: ค่าใช้จ่ายมีงวดบริการ (accrual view ในรายงาน)

- สถานะ: ยอมรับ · วันที่: 2026-09-28

## บริบท
ระหว่าง QA พบว่ารายงาน 7 วันแสดงขาดทุน −฿74k เพราะเงินเดือน/ค่าเช่าทั้งเดือนตกในสัปดาห์ที่จ่าย — ตัวเลขนี้ทำให้เจ้าของร้านตัดสินใจผิด

## การตัดสินใจ
- `app.expenses.period_start/period_end` (ทั้งคู่หรือไม่มีเลย, ≤ 366 วัน)
- `v_branch_daily_pnl` กระจายยอดเท่ากันทุกวันของงวด; `domain.allocateToRange` ใช้สูตรเดียวกันในแอป
- UI เลือกค่าเริ่มต้น "ทั้งเดือน" ให้ค่าเช่า/เงินเดือน/ค่าน้ำไฟ พร้อมคำอธิบายหนึ่งบรรทัด
- บัญชี (journal) ยังบันทึกตามวันที่จ่ายจริง — รายงานเป็น operating view

## ผลที่ตามมา
- ✅ กำไรรายวัน/สัปดาห์สมเหตุสมผล (7 วัน: กำไร 19.5% แทน −35%)
- ✅ มีเทสต์ทั้ง SQL, domain และ API

## 5. ข้อจำกัดที่ต้องรู้ (หมวด H = 80)

1. **Web UI ทำงานบน demo adapter** (engine ในเบราว์เซอร์ที่จำลองคำสั่ง DB ชุดเดียวกัน + ข้อมูลตัวอย่าง 30 วัน) — API พร้อมและผ่านเทสต์แล้ว แต่ยังไม่ได้ต่อสายกับ UI
2. ยังไม่มีหน้าสมัคร/ล็อกอินจริง (ใช้การเลือกบทบาทในร้านตัวอย่าง / สร้างร้านในเครื่อง)
3. ยังไม่มีการพิมพ์ใบเสร็จ/ตั๋วครัว และใบกำกับภาษี
4. CI รัน typecheck + SQL e2e + tests + build แล้ว แต่ยังไม่มี UI e2e/axe/Lighthouse ใน CI, load test และการทดสอบกับผู้ใช้จริง (usability test กับพนักงานร้าน)
5. การทดสอบ accessibility เป็นแบบอัตโนมัติ — ยังไม่ได้ทดสอบด้วย screen reader จริง (VoiceOver/TalkBack)
6. การเทียบคู่แข่งอ้างอิงเอกสารสาธารณะ ไม่ได้ทดลองใช้ทุกระบบด้วยตนเอง
